# Dracula's Feast: New Blood

เกมปาร์ตี้แนว deduce-the-identity สำหรับ 4–8 คน เล่นบนเบราว์เซอร์ได้ด้วยรหัสห้อง ไม่มีบัญชีผู้ใช้ และไม่ต้องมีเซิร์ฟเวอร์เกมของคุณเอง เป็นโปรเจกต์แฟนเมดที่สร้างขึ้นเพื่อเล่นส่วนตัว ไม่ใช่ผลิตภัณฑ์ทางการของเจ้าของเครื่องหมายการค้าเดิม

ในแต่ละตา ให้เลือกหนึ่งอย่าง: ถามแขกเพื่อรับคำตอบ YES/NO ที่จริง, ชวนเต้นรำเพื่อให้ทั้งคู่เห็นตัวตนกัน, หรือกล่าวหาตัวตนของแขกคนหนึ่งให้ถูกต้องเพื่อชนะ

## เล่นบนเครื่อง

เปิด `index.html` ผ่านเว็บเซิร์ฟเวอร์แบบ static (เช่น VS Code Live Server) เพื่อให้การเชื่อมต่อระหว่างผู้เล่นทำงานได้อย่างถูกต้อง

## เผยแพร่ฟรี

อัปโหลดโฟลเดอร์นี้ไปยัง GitHub แล้วเปิด **Settings → Pages → Deploy from a branch → main / root**. จากนั้นทุกคนเข้าลิงก์เดียวกัน เจ้าของห้องกด “สร้างห้องใหม่” และส่งรหัส 5 ตัวอักษรให้เพื่อน

การเชื่อมต่อห้องใช้ PeerJS cloud แบบ peer-to-peer: เกมไม่มีฐานข้อมูลหรือการเก็บชื่อผู้เล่นไว้บนเซิร์ฟเวอร์
